# Slot Machine Game

Game mesin slot sederhana.

## Prasyarat

- Node.js
- npm

## Instalasi

1.  Kloning repositori:
    ```bash
    git clone <url_repositori>
    ```
2.  Arahkan ke direktori proyek:
    ```bash
    cd <direktori_proyek>
    ```
3.  Instal dependensi:
    ```bash
    npm install
    ```

## Menjalankan Aplikasi

Untuk memulai server, jalankan perintah berikut:

```bash
npm start
```

Aplikasi akan tersedia di `http://localhost:5001`.
